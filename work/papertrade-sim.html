Stonks is a paper-trading simulator: build portfolios out of real stocks on real past dates, then ask what they’re worth, what they’re made of and how they’ve done, without putting any money at risk.

What you can do

  • Buy and sell fractional shares on any past trading day, then value a portfolio on any date.
  • See a portfolio’s composition and how its value is distributed across holdings.
  • Rebalance to target weights. They don’t have to add up to 100; each is divided by the total.
  • Plot performance over a week, a month, a year, five years or ten, as a scaled text chart.
  • For a single stock: gain or loss over a range, an x-day moving average, and the days it closed above that average.
  • Save portfolios to disk and load them back.

Where the prices come from

Daily history comes from Alpha Vantage’s full daily time series as CSV and is saved next to the program as TICKER.csv. After the first query the program reads that file offline, and refreshes it from the API once it goes stale the next day. Since it only needs that format (date, open, high, low, close, volume), any CSV you drop in works too, including tickers the API doesn’t cover and histories older than its data.

One model, two interfaces

The code is model-view-controller. The models build in layers, from a simple stock manager to an advanced one with dates, rebalancing and saving, and the text menus and the Swing GUI are separate controllers and views over the same model.

Validation

Bad input sends you back to the menu with the reason: impossible dates like 2023-30-33, dates in the future, dates before a stock existed, unknown tickers, and selling more shares than a portfolio holds. Stock splits aren’t adjusted for, which is the main known limitation.

How it’s tested

273 JUnit tests across the models, portfolios, stocks and data sources, with mock-based tests for the text views and controllers. Some tests deliberately call the live API, since fetching prices is central to the program, so the suite needs a connection and runs best one class at a time to stay under the API’s rate limit.
